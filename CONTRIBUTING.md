# Contributing to ApkStart International

Thanks for helping. This is an independent fork, not an official RoutineMiku release.

1. Open an issue describing a bug, translation gap, or proposal before making broad architectural changes.
2. Use English for issue titles and code discussions, with Vietnamese or Chinese when helpful.
3. Keep translation keys synchronized across `en.json`, `vi.json`, and `zh-CN.json`.
4. Run `npm run i18n:build`, `npm run test:international`, and `npm run audit:international` before a PR.
5. Preserve upstream `LICENSE` and attribution, and report third-party licensing concerns.
6. Do not commit device images, keys, access tokens, Google proprietary components or compiled runtime packages to the Git repository.
7. Report security problems privately to the maintainer rather than publishing exploit details immediately.

Please also read the archived [original contributing guidelines](docs/UPSTREAM_CONTRIBUTING.zh-CN.md) for upstream-specific considerations.
