## Windows Developer Preview

ApkStart International runs Android apps in separate Windows windows and gives each Android Profile its own app catalog and userdata. This unsigned x64 preview is for testing. Stable 1.0 remains blocked.

### What was verified

On Windows Server 2025, API Demos and Fossify Calculator installed through Explorer, opened from their Profile-specific shortcuts, and passed minimize, maximize and restore checks. An encrypted 5.41 GB migration between two Profiles on one host preserved the app's private data after a cold boot. The Linux Android 14 guest passed all 26 phases. Windows Node 20 and 22 each passed 240 international tests. [Windows build](https://github.com/alexanderajohn/apkstart-international/actions/runs/46043750085) · [Android results](https://github.com/alexanderajohn/apkstart-international/actions/runs/46043742272)

### Known limits

Android sometimes shows a nonresponding system dialog when opening App Manager split packages. The Windows 720p guest also failed a Quick Boot wake check. Physical Windows 10/11, GPU coverage, migration between computers, power-loss recovery and production signing remain open.

**Dùng thử:** Chọn Portable hoặc Setup, kiểm tra mã SHA-256 và bắt đầu bằng một Profile mới. Hãy giữ bản sao lưu ngoại tuyến trước khi dùng dữ liệu đang có. Gói Windows này chưa ký. Nếu thiết bị yêu cầu chữ ký của nhà phát hành, hãy dừng tại bước đó.
